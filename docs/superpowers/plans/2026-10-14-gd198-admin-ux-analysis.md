**추천은 실패한 알림 생성 작업과 최근 감사 로그입니다.**

- 알림 실패 요약은 확정된 API를 사용하고 운영자의 다음 행동이 명확합니다. 실패 목록의 일부만 받아도 전체 실패 건수는 정확히 표시할 수 있습니다.
- 감사 로그는 현재 총건수만 있는 카드 아래에 “무슨 일이 있었는지”를 채웁니다. 기존 목록·상세 표시를 재사용할 수 있습니다.
- 감사 로그 정렬이 실서버에서 보장되지 않으면 제목을 “감사 로그 미리보기”로 사용하고, 정렬 확인 후 “최근”으로 변경합니다.
- `retryable`인 미리보기 행의 개수를 전체 복구 가능 건수처럼 표시하지 않습니다. 서버에 해당 집계 필터가 없습니다.

추천 배치는 기존 4개 지표 아래에 두 패널을 놓는 구조입니다. 넓은 화면에서는 2열, 작은 화면에서는 1열로 배치하고 패널마다 최대 5건·전체보기·새로고침을 제공합니다. 한 패널의 조회 실패가 다른 패널을 숨기지 않도록 상태를 분리합니다.
